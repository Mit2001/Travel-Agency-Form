# Travel Agency Inquiry Form Automation
This project is an end-to-end workflow automation built with **n8n** for managing travel inquiries.

## Features

- 📝 Collect travel inquiries through an online form
- ✅ Validate user input using custom JavaScript
- 📧 Send an automated confirmation email to the customer
- 📊 Store all validated submissions in Google Sheets
- ⚡ Fully automated workflow with no manual intervention

## Tech Stack

- n8n
- JavaScript
- Google Sheets
- Gmail
- Forms

## Workflow

User submits the travel inquiry form
        ↓
JavaScript validates the submitted data
        ↓
Valid data is stored in Google Sheets
        ↓
A confirmation email is automatically sent to the customer's email address
