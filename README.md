# Travel Agency Inquiry Form Automation using n8n
This project is an end-to-end workflow automation solution built with n8n to simplify and automate the travel inquiry process for travel agencies. It demonstrates how no-code automation, JavaScript, Google Sheets, and email services can be integrated to create a seamless customer inquiry management system.

The workflow begins with an online travel inquiry form where customers provide essential details such as their name, email address, phone number, destination, departure city, travel dates, trip duration, number of travelers, budget, hotel preference, visa requirements, flight booking requirements, and any special requests.

Once the form is submitted, the data is processed through a custom JavaScript validation step to ensure the submitted information is accurate and complete. The validation checks for missing or invalid values, helping prevent incorrect or incomplete data from entering the workflow.

After successful validation, the inquiry is automatically stored in Google Sheets, creating a centralized database that travel agents can use to manage, track, and review customer requests without manual data entry.

The workflow also generates and sends a personalized confirmation email to the customer using their provided email address. The email acknowledges the successful submission, includes a summary of the inquiry, and informs the customer that a travel consultant will review the request and respond with personalized travel recommendations within 24 hours.

This project highlights practical applications of workflow automation, custom JavaScript logic, cloud-based data management, and email automation. It serves as a real-world example of how repetitive business processes can be automated to improve efficiency, reduce manual work, minimize errors, and enhance the overall customer experience. It is an excellent portfolio project for demonstrating skills in n8n, JavaScript, Google Sheets integration, workflow automation, and business process automation.
